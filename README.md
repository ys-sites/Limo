# Premier Limo - Luxury Chauffeur & Limousine Service

A high-performance luxury limousine and chauffeur booking web application built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Vite**.

Designed for seamless deployment to **GitHub** and **Vercel**.

---

## ✨ Features

- **Cinematic Luxury Hero Section**: Features executive black Cadillac Escalade imagery with an integrated, floating multi-mode reservation widget.
- **Interactive Ride Calculator**: Switch between *Distance*, *Hourly*, and *Flat Rate* rides with autocomplete airport and hotel suggestions.
- **Section 01 · Our Services**: Editorial showcase for corporate travel, private aviation airport transfers, weddings, and intercity transit.
- **Section 02 · Our Fleet**: Vehicle catalogue with category filters (`ALL`, `SEDAN`, `LUXURY`, `LIMOUSINE`, `SUV`), passenger and luggage capacities, and live hourly/day pricing.
- **Hot Offer Spotlight ("Only today $75/day")**: Limited-time promotion featuring the Cadillac Escalade ESV with presidential executive features.
- **Why Choose Us**: 4 service pillars highlighting verified chauffeurs, late-model fleets, and transparent billing.
- **Section 03 · Top Cities**: Interactive global hub selector (New York, London, Chicago, Atlanta, Boston, Houston) with direct airport transfer route links.
- **Executive Reservation Concierge**: Complete digital booking checkout modal with real-time rate calculations (base rate, taxes, chauffeur gratuity) and digital boarding pass generation.
- **Luxury Dark Footer**: Newsletter subscription, directory links, and social channel integration.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/premier-limo.git
cd premier-limo

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be accessible at `http://localhost:3000`.

---

## 🚢 Deploying to Vercel

This repository includes a pre-configured `vercel.json` optimized for Vite:

1. Push this project to your GitHub repository.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**.

Build settings:
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
